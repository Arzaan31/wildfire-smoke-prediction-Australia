# wildfire-smoke-prediction-Australia
Data-driven wildfire smoke impact prediction and air quality forecasting for Australia using satellite fire detections, PM2.5 observations, meteorological data, and machine learning.
 
This project develops machine learning models to predict wildfire smoke impacts and PM2.5 concentrations across Australia.
 
Datasets:
- DEA Hotspots
- PM2.5 Monitoring Stations / CARDAT PM2.5
- ERA5 Weather
